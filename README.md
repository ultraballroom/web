# Web UltraBall

Web statis (HTML/CSS/JS biasa, tanpa build). Tayang otomatis lewat Vercel setiap ada perubahan di GitHub.

## Cara update isi
- **Semua data** (koleksi, jersey dijual, review) ada di `data.js`.
- **Foto** taruh di folder `foto/`, lalu tulis nama filenya di kolom `foto` pada `data.js`.
- **Nomor WhatsApp** ganti di baris `WHATSAPP` paling atas `data.js`.

## Halaman
- `index.html` — Home
- `koleksi.html` — The Vault (koleksi pribadi)
- `review.html` + `artikel.html` — Review jersey
- `jual.html` — Ready Stock
